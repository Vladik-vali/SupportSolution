# Модульная структура решения

| Модуль | Ответственность | От чего зависит | Почему |
|---|---|---|---|
| `Support.Domain` | Сущности и бизнес-правила (заявка, статусы) | — | Ядро системы. Не зависит от технологий и баз данных. |
| `Support.Application` | Контракты (интерфейсы) и сценарии (Use Cases) | Domain | Оркестрация бизнес-правил. Знает, *что* делать, но не *как*. |
| `Support.Infrastructure` | Технические реализации (репозитории, БД) | Application, Domain | Реализует интерфейсы из Application. Содержит технические детали. |
| `Support.WebApi` | HTTP-интерфейс (контроллеры, endpoints) | Application, Infrastructure | Точка входа. Принимает запросы, вызывает сценарии. |
| `Support.UnitTests` | Модульные тесты | Domain, Application | Проверяет корректность бизнес-правил. |
